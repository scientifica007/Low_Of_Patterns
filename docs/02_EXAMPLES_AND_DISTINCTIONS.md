# 02 — أمثلة وتمييزات أساسية

## 1. عجلة السيارة: المثال المرجعي

عجلة السيارة توضح أن الدورة لا تحتاج إلى عودة مطلقة في الفضاء.

بالنسبة إلى مركز العجلة، بعد دورة كاملة:

```math
\theta \mapsto \theta + 2\pi
```

وتعود النقطة إلى موضعها النسبي نفسه على العجلة.

لكن بالنسبة إلى الطريق، إذا تحركت السيارة، يكون الموضع الخارجي قد تغير:

```math
x \mapsto x + 2\pi R
```

إذن:

```text
عودة داخلية + انتقال خارجي
```

وهذا المثال أساسي في المشروع لأنه يفصل بين **الدورة الداخلية** و**المسار الخارجي**.

## 2. المتتالية a_n = n^2

القيم:

```math
1,4,9,16,25,\ldots
```

لا تتكرر، لكن هذا لا يعني غياب الدورة وفق المفهوم الموسع.

البنية التي يعاد تحققها هي:

```math
n \mapsto n^2
```

فتصبح القيم نقاطًا خارجية مختلفة لبنية داخلية ثابتة.

الدرس:

> السؤال ليس فقط: هل القيم تتكرر؟ بل: **أين تقع الدورة؟**

## 3. التكرار في قاعدة التحويل

في:

```math
a_{n+1}=2a_n
```

لدينا:

```math
2,4,8,16,32,\ldots
```

القيم لا تعود، لكن العملية:

```math
\times 2
```

تعاد في كل انتقال.

إذن يمكن أن تقع الدورة في **التحويل** لا في الحالة.

## 4. القانون كعودة علاقة

في قانون من الشكل:

```math
R(x,y)=0
```

قد تتغير `x` و`y` من حالة إلى أخرى، بينما تبقى العلاقة `R` نفسها.

مثال:

```math
y=2x
```

يعطي:

```math
(1,2),(2,4),(3,6),(100,200)
```

لا تتكرر الأزواج، لكن العلاقة:

```math
\frac{y}{x}=2
```

تعود.

## 5. الدورة المولدة والدورة الحاوية

### 5.1 الدورة المولدة

تحدد النتيجة من الشروط:

```math
C \xrightarrow{L} R
```

مثل:

```math
n \mapsto n^2
```

### 5.2 الدورة الحاوية

تحدد الوعاء أو فضاء الإمكان، دون أن تحدد الحدث المفرد:

```math
\omega \in \Omega
```

وقد نعرف أيضًا توزيعًا:

```math
P(\omega)
```

لكننا لا نملك بالضرورة قانونًا يحدد أي `ω` سيظهر في التحقق التالي.

## 6. العشوائية والكأس

التشبيه المعتمد في الجلسة:

> يمكن دراسة الكأس التي تحتوي الظواهر العشوائية دون أن يعني ذلك أننا وضعنا قانونًا للعشوائية المفردة ذاتها.

لدينا مثلًا:

```math
X \in \{0,1\}
```

و:

```math
P(X=0)=P(X=1)=\frac12
```

هذا يصف بنية المجال أو «الكأس»، لكنه لا يحدد:

```math
X_{n+1}=0
```

أم:

```math
X_{n+1}=1
```

إذا كانت النتيجة عشوائية حقًا.

التمييز المهم:

```text
قانون الوعاء ≠ قانون يحدد الحدث العشوائي المفرد
```

## 7. الجهل مقابل العشوائية الحقيقية

### الجهل

قد تكون هناك بنية مولدة أو قانون فعلي، لكننا لا نعرفه.

```text
دورة موجودة + معرفة ناقصة
```

### العشوائية الحقيقية

بالصياغة القوية المستخدمة في المشروع: لا يوجد قانون حتمي يحدد التحقق المفرد من الشروط السابقة.

يجب عدم الخلط بين هذه الحالة وبين وجود قوانين احتمالية أو قيود على فضاء الممكنات؛ هذه قد تكون خصائص للكأس الحاوي.

## 8. اللغة

الجمل:

```text
كتب الطفل الدرس.
أكل الرجل الطعام.
قرأ الطالب الكتاب.
```

مختلفة خارجيًا، لكن يمكن أن تحقق بنية نحوية واحدة:

```text
فعل + فاعل + مفعول به
```

ما يعود هنا هو البنية لا الجملة.

حتى الرمز نفسه يحتاج إلى إمكان إعادة التعرف:

```math
A_1 \neq A_2
```

كآثار كتابية مادية، لكن:

```math
A_1 \sim A_2
```

كرمز واحد.

## 9. المنطق

قاعدة Modus Ponens:

```text
P
P → Q
∴ Q
```

يمكن أن تطبق على مضامين مختلفة بلا حد. ما يعاد هو **شكل الاستدلال**.

## 10. السنة والزراعة

لا توجد سنتان متطابقتان:

```math
Y_1 \neq Y_2
```

لكن توجد عودة بنيوية موسمية كافية لإنتاج التعلم الزراعي:

```text
ملاحظة → ذاكرة → نمط → توقع → قرار زراعي
```

الفكرة ليست أن السنة دائرة مثالية، بل أن بعض الحالات والعلاقات تعود بما يكفي لكي يصبح الماضي مفيدًا للمستقبل.

## 11. الإدراك والتوقع

الإشارات العصبية ومعالجتها تستغرق زمنًا؛ لذلك يعتمد الكائن على معلومات عن ماض قريب لبناء تقدير للحاضر وتوقع للمستقبل القريب.

صياغة مفاهيمية:

```text
الماضي المدرك + النمط المكتشف → تقدير الحاضر + توقع المستقبل
```

وهنا تظهر قيمة العود البنيوي للحياة التكيفية.

## 12. صياغة جامعة للأمثلة

```text
الماضي يقدم التحققات
النمط يكشف العودة
القانون يصوغها
التوقع يمدها إلى المستقبل
الفعل يستثمرها
```
